# Engineering Rules Index

Mục lục các quy chuẩn kỹ thuật và chỉ dẫn bắt buộc dành cho Developer và AI Agent khi phát triển mã nguồn trong dự án.

> [!NOTE]
> Thư mục `docs/rules/` quy định các tiêu chuẩn kỹ thuật (Engineering & Development Rules), hoàn toàn độc lập với các yêu cầu nghiệp vụ sản phẩm (Product Requirements / PRD trong `docs/prd/`).

## Danh mục Quy tắc kỹ thuật

| Quy tắc | File tài liệu | Mục đích & Thời điểm bắt buộc đọc |
|---|---|---|
| **Clean Code** | [clean-code.md](clean-code.md) | Trước khi viết hoặc sửa code; quy tắc cấu trúc hàm, xử lý lỗi, log và comment |
| **Coding Style** | [coding-style.md](coding-style.md) | Trước khi viết code; quy ước cú pháp TypeScript, NestJS, React |
| **Naming Conventions** | [naming.md](naming.md) | Trước khi đặt tên file, class, method, biến, bảng CSDL, endpoint |
| **REST API Rules** | [rest-api.md](rest-api.md) | Trước khi thiết kế hoặc cài đặt REST endpoint, DTO, HTTP status, pagination |
| **Security Rules** | [security.md](security.md) | Trước khi xử lý xác thực, phân quyền, dữ liệu nhạy cảm, log và input validation |
| **Testing Rules** | [testing.md](testing.md) | Trước khi viết test và trước khi báo hoàn thành một tác vụ |
| **UI Rules** | [ui.md](ui.md) | Trước khi viết hoặc sửa giao diện frontend (design tokens, components, form UX) |
| **Git Rules** | [git.md](git.md) | Trước khi branch, commit, push, PR |
| **Database Rules** | [database.md](database.md) | Quy chuẩn thiết kế schema, quan hệ và migrations |

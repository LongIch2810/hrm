# HRM frontend prototype

Giao diện React dùng dữ liệu giả lập để xem các màn hình HRM. Backend và API chưa được kết nối.

## Chạy cục bộ

Phiên bản Node.js mục tiêu đã xác nhận là 22.22.2; dùng npm theo [Tech Stack](../docs/architecture/tech-stack.md).

```powershell
npm install
npm run dev
```

Mở địa chỉ do Vite in ra, mặc định `http://127.0.0.1:5173`. Dùng DevToolbar để đổi vai trò và xem màn hình.

## Kiểm tra bản dựng

```powershell
npm run build
npm run preview
```

Project hiện chưa cấu hình script test, lint hoặc format.

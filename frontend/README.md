# HRM frontend prototype

Giao diện React dùng dữ liệu giả lập để xem các màn hình HRM. Backend và API chưa được kết nối.

## Chạy cục bộ

Yêu cầu Node.js 20 LTS và npm.

```powershell
npm install
npm run dev
```

Mở địa chỉ do Vite in ra, mặc định `http://localhost:5173`. Dùng DevToolbar để đổi vai trò và xem màn hình.

## Kiểm tra bản dựng

```powershell
npm run build
npm run preview
```

Project hiện chưa cấu hình script test, lint hoặc format.
